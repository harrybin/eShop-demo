# Onboarding Guide: local/eShop

## Prerequisites Checklist

- [ ] Docker Desktop installed and running
- [ ] Visual Studio 2022 v17.10+ with ASP.NET workload and .NET Aspire SDK (Windows), OR
- [ ] .NET 10 SDK (Mac/Linux/Windows without VS)
- [ ] Optional: Visual Studio Code with C# Dev Kit
- [ ] Optional: .NET MAUI workload for mobile client

## Clone & Install

```bash
# Clone the repository
git clone https://github.com/local/eShop.git
cd eShop

# Install dependencies
npm install
```

## Available Commands

### Run application
```bash
dotnet run --project src/eShop.AppHost/eShop.AppHost.csproj
```


### Run local HTTP-only
```bash
./build/local/run-local.ps1
```


### Run local with HTTPS
```bash
./build/local/run-local.ps1 -UseHttps
```


### Build solution
```bash
dotnet build eShop.Web.slnf
```


### Run tests
```bash
dotnet test --solution eShop.Web.slnf
```


### Run Playwright e2e tests
```bash
npm install && npx playwright test
```

## Common Errors & Fixes

### Docker is not running
**Fix:** Start Docker Desktop and ensure it's fully running before launching the application

### Port conflicts on 19888 or other ports
**Fix:** Stop other services using those ports or restart Docker Desktop

### HTTPS certificate trust issues
**Fix:** Run 'dotnet dev-certs https --trust' and close all browser tabs
