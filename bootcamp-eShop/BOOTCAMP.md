# local/eShop Bootcamp

![Confidence: High](https://img.shields.io/badge/confidence-high-brightgreen)

> A reference .NET application implementing an e-commerce website using microservices architecture

eShop is a .NET Aspire-based reference application showcasing a services-based e-commerce platform. It demonstrates microservices patterns with Catalog, Basket, Ordering, Identity, and Webhook APIs, uses PostgreSQL with pgvector for data storage, RabbitMQ for event-driven communication, and Redis for caching. The application includes a Blazor-based WebApp, MAUI mobile client support, and integrates OpenTelemetry for observability.

- .NET 10 SDK (Mac/Linux/Windows without VS)
- Optional: Visual Studio Code with C# Dev Kit

## Quick Start

1. Clone the repository from https://github.com/dotnet/eshop
2. Ensure Docker Desktop is running
3. Open eShop.Web.slnf in Visual Studio and set eShop.AppHost as startup project, OR run from terminal
4. Press Ctrl-F5 in VS or execute the dotnet run command
5. Open the Aspire dashboard URL shown in console output (http://localhost:19888/login?t=...)
6. Access the eShop web application through the Aspire dashboard

**Key commands:** `dotnet run --project src/eShop.AppHost/eShop.AppHost.csproj`, `./build/local/run-local.ps1`, `./build/local/run-local.ps1 -UseHttps`, `dotnet build eShop.Web.slnf`, `dotnet test --solution eShop.Web.slnf`

## Project Structure

- `src/` - All application source code organized by service/component
- `src/eShop.AppHost/` - .NET Aspire orchestration host - configures and launches all services
- `src/Catalog.API/` - Product catalog microservice with PostgreSQL and vector search
- `src/Basket.API/` - Shopping basket microservice using Redis and gRPC
- `src/Ordering.API/` - Order management microservice with domain-driven design

## If You Only Have 30 Minutes

1. Read this document
2. Run the dev server: `dotnet run --project src/eShop.AppHost/eShop.AppHost.csproj`
3. Pick one of these starter tasks:

- **Add product filtering by price range**: Extend the Catalog API to accept min/max price query parameters and filter results. Update the CatalogApi.cs GetAllItems endpoint.
- **Add unit tests for BasketService gRPC endpoints**: Create comprehensive tests for the basket gRPC service methods (GetBasket, UpdateBasket, DeleteBasket) using NSubstitute mocks.
- **Improve error messages in CONTRIBUTING.md**: Expand the contribution guide with common development pitfalls (Docker not running, certificate trust issues, port conflicts) and their solutions.
